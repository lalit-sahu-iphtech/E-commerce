## 📥 Clone the Repository

```bash
git clone https://github.com/lalit-sahu-iphtech/E-commerce.git
```

---

## 📂 Go to Project Folder

```bash
cd E-commerce/E-Commerce-app
```

---

## 📦 Install Dependencies

```bash
npm install
```

---

## ▶️ Run the Project

```bash
npm run dev
```

Open your browser:

```
http://localhost:5173
```

---

## 📦 Build for Production

```bash
npm run build
```
